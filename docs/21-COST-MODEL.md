# 21 - Cost model

No provider prices or subscription prices are assumed. At integration, record provider documentation
date and account-specific terms for STT minutes/channels, LLM input/output/cache tokens, embeddings,
storage, egress, background jobs, monitoring, and CI.

Model cost per meeting and subscriber using observed usage, retry rates, concurrency, and retention.
Separate two-channel STT billing from meeting wall-clock minutes. Set server-side budgets and abuse
limits before enabling paid operations. Test pessimistic long-meeting and reconnect scenarios.
Pricing, margin targets, taxes, and legal/account ownership require owner approval.
