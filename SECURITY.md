# Security reporting

This is an unpublished foundation, not a production release. Do not use it for sensitive meetings.

Report security issues privately through this repository's GitHub security advisory channel when
available, or directly to the repository owner using an existing private contact. Do not post
credentials, transcripts, audio, or exploitable details in public issues.

Include affected version, reproduction using synthetic data, impact, and suggested mitigation.
No response-time SLA or bounty is offered. Never test against other users' accounts or production
services without explicit authorization.

Engineering requirements are in docs/14-SECURITY-PRIVACY-LEGAL.md.
